1 · SEO Routes

Dashboard tabs promoted to real routes

The site was a single-page dashboard driven by ?tab= URL params — invisible to search engines as distinct pages. Each tab is now a real route (/comparison, /side-by-side, /spec-select, /glossary, /explore) with its own metadata and canonical URL, built as a thin server page wrapping a small client component.

  • 301 redirects from all old ?tab= URLs; internal links updated.
  • Sitemap lastModified now driven by the dataset's last_updated field.
  • Dead Dashboard / NavTabs components deleted.
2 · Visual Identity

Vehicle theming single-sourced

Badge CSS classes and chart colors were defined in four diverging places. Now lib/vehicle-theme.ts is the single source of truth (VEHICLE_CLASSES + CLASS_THEMES), re-exported for existing imports. Also fixed light-theme chart colors and gray chart fallbacks.

3 · Data Model

Computed prices + build-time validation

Out-the-door prices (otd_new, otd_preowned) and pre-owned low/high were stored in ev-data.json and could drift from MSRP. They are now computed at load in lib/data.ts from msrp / destination / preowned_range, with named tax/fee constants.

  • A validator (scripts/validate-data.js) is wired into the build and errors if a stored OTD field ever reappears.
  • Also checks required fields, count-total consistency, preowned↔details sync, duplicate names.
4 · Chart Convergence

One chart library: Chart.js

The Explore scatter used Observable Plot + d3 while every other chart used Chart.js. DataExplorer was ported to Chart.js / react-chartjs-2 with a custom plugin reproducing the median crosshair and quadrant labels. @observablehq/plot, d3, and @types/d3 removed entirely.

Bug found along the way: Number(null) coerced missing prices to 0, plotting phantom $0 dots on price axes. Pre-existing; fixed and verified with screenshots in both themes.
5 · Hygiene

Housekeeping sweep

  • Filter clicks use router.replace() — no more history-stack spam; filters live in shareable URL params.
  • Playwright smoke harness covering all nine routes, with a PW_PORT override to run beside a busy dev server.
  • Report files organized into docs/; dead CSS and code pruned.
