New

Redesigned Vehicle Pages

Each vehicle now has a dedicated page with a clean, scannable layout — built for both quick shoppers and deep researchers.

  • Desktop: Side-by-side trim comparison table — compare every spec across all trims at a glance
  • Mobile: Accordion cards with collapsible spec sections and a trim picker for quick navigation
  • SEO preserved: All spec data remains in the DOM for search engine crawlers
  • “Keep Exploring” CTAs: Deep links back to the dashboard’s Comparison and Side-by-Side tools, pre-filtered to the vehicle
New

Mobile-Friendly Comparison Pages

The 130+ vehicle-vs-vehicle comparison pages now render beautifully on mobile. The cramped 3-column table is replaced with stacked metric cards showing each vehicle’s value with color-coded highlights.

Improved

Improvements & Enhancements

  • Full navigation bar everywhere: Vehicle and comparison pages now show the same nav tabs as the dashboard — jump to any section from any page
  • Detail Panel links: “View full page” link in the spec panel header takes you to the vehicle’s dedicated page
  • Clickable badges: Vehicle badges in Speed Dating and mobile cards are now linked to their dedicated pages
  • 6-Seat filter fix: Speed Dating now correctly filters to 6-seat trims only, not all trims from vehicles that offer a 6-seat option
Bug Fixes

Fixes & Corrections

  • Neutral color coding: Seats and Ground Clearance no longer show red/green grading on comparison pages — these are buyer-preference metrics, not “more is better”
  • Full Monty layout: Fixed clear-filters button overlapping text on smaller screens
  • Glossary cleanup: Removed redundant OTD, Make/Model, and Vehicle entries
  • Mobile hero image: Fixed aspect ratio and header alignment on mobile
